# 接线与引脚分配指南

本文档描述麦克纳姆轮机器人的完整接线拓扑、STM32 定时器分配策略和 Raspberry Pi 5 连接。由于项目在硬件选型阶段，具体的 GPIO 引脚号和定时器分配需在 STM32CubeMX 配置完成后最终确认。

---

## 总体接线框图

```
┌─────────────────────────────────────────────────────────────────┐
│                      电源系统 (Power Bus)                        │
│  3S 锂电池(11.1V) → 保险丝 → 开关 → [12V 总线 + 滤波电容]     │
│                            ├→ Mini560 #1 → 5.1V (Pi + LD06)    │
│                            └→ Mini560 #2 → 5V (STM32 + 传感器)  │
└─────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────┐
│      STM32 MCU (FreeRTOS)            │
│  ┌──────────────────────────────┐   │
│  │ TIM2/3/4/5 (4×TIM)           │   │
│  │ ├─ 编码器模式 (CH1+CH2)      │   │
│  │ └─ PWM 驱动 (CH3/CH4/其他)   │   │
│  │                              │   │
│  │ USART DMA ←→ Raspberry Pi 5  │   │
│  │ I2C ←→ IMU (MPU6050)         │   │
│  │ I2C ←→ ToF (VL53L0X)         │   │
│  └──────────────────────────────┘   │
│                                      │
│  ┌─ GPIO (DIR) ─────┐               │
│  │ TB6612 #1 (STBY) │ ← PWM         │
│  │ TB6612 #2 (STBY) │ ← PWM         │
│  └──────────────────┘               │
└──────────────────────────────────────┘
         │                    │
         │                    └────────────────┐
         │                                     │
         ▼                                     ▼
    [12V 总线]                    ┌─────────────────────────┐
         │                        │  Raspberry Pi 5         │
    ┌────┴────┐                   │  (Ubuntu 24.04 + ROS2)  │
    │ 4个电机 │                   │                         │
    │ +编码器 │                   │ LD06 激光雷达(UART-USB) │
    └────┬────┘                   │ USB 摄像头              │
         │                        │ 5V GPIO 供电            │
    TB6612 ×2                      └─────────────────────────┘
    H-Bridge
```

### 细节连接说明

**电机供电链路：**
- 12V 总线 → TB6612 #1 VM + TB6612 #2 VM （各配 1000μF 电解电容并联滤波）
- TB6612 逻辑电源 (VCC) → STM32 板载 3.3V LDO 输出 **（不要接 5V，防止 GPIO 烧毁）**
- TB6612 #1: 控制电机 FL + FR (2个通道)
- TB6612 #2: 控制电机 RL + RR (2个通道)

**信号连接：**
- STM32 GPIO (DIR) → TB6612 方向控制引脚 (A, B)
- STM32 TIM PWM → TB6612 PWM 使能引脚 (PWMA, PWMB)
- STM32 TIM 编码器模式 → 电机编码器 (A, B 相位)
- STM32 I2C1 → MPU6050 (SCL, SDA)
- STM32 I2C2 → VL53L0X (SCL, SDA)（可选：某些 ToF 模块支持 UART，但 I2C 更常见）
- STM32 UART1 (TX/RX + DMA) ←→ Raspberry Pi UART (GPIO 14/15)
- 共地：所有模块 GND 连接到电池负极

**Raspberry Pi 5 外设：**
- GPIO Pin 2/4 (5V) ← Mini560 #1 输出
- GPIO Pin 6 (GND) ← Mini560 #1 GND
- GPIO 14/15 (UART) ← STM32 UART1 (TX/RX 交叉)
- USB 口 A: LD06 激光雷达（UART-to-USB 适配板）
- USB 口 B: USB 摄像头

## STM32 定时器 (TIM) 分配方案

### 核心设计原则

**关键约束：** 编码器模式会让定时器计数器由 TI1/TI2 边沿驱动；PWM 的周期和比较也依赖同一个计数器。因此不能把同一实例的 CH1/CH2 用作编码器，同时指望 CH3/CH4 生成固定频率电机 PWM。编码器和 PWM 必须使用不同的定时器实例。

当前优先把自制 STM32F407VET6 板作为底盘控制器候选：TIM2/3/4/5 分别采集四路编码器，TIM1/TIM8 提供四路 20 kHz PWM。最终仍要在 CubeMX 中结合 LQFP100 实际引脚和板上排针复核冲突。

### 推荐分配方案

| 定时器 | 用途 | 通道 | 备注 |
|--------|------|------|------|
| TIM2 | 电机 FL 编码器 | CH1+CH2 | 32 位计数器，实际引脚待 CubeMX 确认 |
| TIM3 | 电机 FR 编码器 | CH1+CH2 | 16 位，软件处理回绕 |
| TIM4 | 电机 RL 编码器 | CH1+CH2 | 16 位，软件处理回绕 |
| TIM5 | 电机 RR 编码器 | CH1+CH2 | 32 位计数器 |
| TIM1 | FL/FR PWM | CH1+CH2 | 统一 20 kHz PWM 周期 |
| TIM8 | RL/RR PWM | CH1+CH2 | 统一 20 kHz PWM 周期 |

### PWM 驱动方案

- 使用 TIM1/TIM8 的输出比较通道产生固定 20 kHz PWM。
- TIM6/TIM7 没有外部 PWM 输出通道，不能直接拿来驱动 TB6612。
- 四路 PWM 统一周期，只改变 CCR 占空比；方向继续由 GPIO 控制。

### 实际应用

以 STM32F407VET6 为候选，**请在 STM32CubeMX 中：**
1. 配置 TIM2/3/4/5 为 **Encoder Mode（4x counting）**
2. 在相应通道添加中断处理溢出计数
3. 将 TIM1/TIM8 配成四路 PWM，目标频率 20 kHz
4. 在 `motor.h` 和 `encoder.h` 中更新对应的 GPIO 和定时器常数

| VL53L0X ToF | I2C2 | I2C2 (SCL/SDA) | PB10(SCL), PB11(SDA) | 距离测量 (避障) | 地址: 0x29 或可配置 |
| Raspberry Pi 5 | UART + DMA | USART1 + DMA | PA9(TX), PA10(RX) | 命令/反馈通信 | 波特率 115200 bps |

**注意事项：**
- 所有引脚号（PA0-PA15, PB0-PB15 等）为**示例**，实际应根据 STM32 芯片选型和可用引脚情况调整
- TIM2/3/4/5 为通用定时器，编码器模式要求 CH1+CH2 同时可用；部分引脚可能复用于其他功能（如 UART/I2C），需在 CubeMX 中逐一检查
- I2C 总线可配置不同速率（标准 100 kHz 或快速 400 kHz），确保 MPU6050 和 VL53L0X 兼容
- UART DMA 需配置接收和发送，推荐圆形缓冲区处理，避免溢出

```

  │
  ├─ XT60 接头 (防反接)
  │
  ├─ 10A 刀片式保险丝
  │
  ├─ 船型开关 (主电源开关)
  │
  ├──→ 【电机供电总线 (12V 直连)】
  │     ├─ 1000μF 25V 电解电容 ×2 (并联滤波，吸收堵转尖峰)
  │     ├─ TB6612 #1 VM 引脚 (电机 FL + FR)
  │     └─ TB6612 #2 VM 引脚 (电机 RL + RR)
  │
  ├──→ 【Mini560 降压模块 #1: 12V → 5.1V / 5A】
  │     ├─ Raspberry Pi 5 (GPIO Pin 2/4 供电)
  │     └─ LD06 激光雷达
  │
  └──→ 【Mini560 降压模块 #2: 12V → 5V / 3A】

```

### 功率预算和设计决策

|------|------|---------|---------|---------|
| 树莓派 5 | 5V | 2.5A | 5A | 12W |
| STM32 开发板 | 5V→3.3V | 0.1A | 0.2A | 0.5W |
| LD06 激光雷达 | 5V | 0.35A | 0.5A | 2W |
| 电机 ×4 (正常运行) | 12V | 0.5A ×4 | — | 24W |
| 电机 ×4 (堵转尖峰) | 12V | — | 1.5A ×4 | 72W |

| TB6612 逻辑电路 ×2 | 5V | 0.01A | — | 忽略 |
| MPU6050 + VL53L0X | 3.3V | 0.01A | — | 忽略 |
| **系统合计** | — | **~5A @ 12V** | **~8A @ 12V** | **~40W 典型** |

#### 为什么使用 2 个 Mini560 而不是 1 个

电机启动或堵转时，12V 总线会产生噪声尖峰（高频纹波和浪涌）。分离电源的好处：

1. **降低负载互扰**：Pi 与 MCU 分开稳压，减少 Pi 瞬态负载直接拉低 MCU 5 V 支路的概率。
2. **便于分别滤波和测量**：可以独立观察两路 5 V 纹波并按负载配置电容。
3. **独立稳压**：两路输出可独立调整，Pi 需要 5.1V（补偿线损），STM32 需要稳定 5V。

两路降压仍共用 3S 电池，不是电气隔离，也不是电源冗余。12 V 总线整体坍塌时两路都会掉电；安全策略不能依赖 MCU 在总线故障后继续运行。

TB6612 的 VM 绝对最大值接近 3S 满电电压，具体裕量必须按所购模块和数据手册确认，并测量制动/堵转尖峰；没有足够裕量时改用额定电压更高的驱动器。

#### TB6612 双电源设计

TB6612 有两组电源引脚，设计上已隔离电机噪声：

- **VM**（电机电源）：接 12V 总线，可串联 100Ω 磁珠进一步吸收高频噪声（可选）
- **VCC**（逻辑电源）：建议接 STM32 板载 3.3V，使输入阈值与 3.3V GPIO 匹配。VCC 本身不会反向给 GPIO 灌入 5V，但选择 5V 时必须重新核对输入高电平阈值，当前设计不采用。

这种设计天然隔离了电机和逻辑电路的电源，是行业标准做法。

## 首次上电检查清单

**重要：严格按照以下顺序操作，确保没有接线错误导致器件损伤。**

### 第一步：测试降压模块（**电池未连接，进行干测试**）

- [ ] 用恒流源或万用表测试 Mini560 #1 输出：应为 5.1V ±0.1V
- [ ] 用恒流源或万用表测试 Mini560 #2 输出：应为 5.0V ±0.1V
- [ ] 确认所有电解电容极性正确（长脚=+，短脚=-）
- [ ] 确认保险丝完好（用万用表欧姆档检测）

### 第二步：连接电池和启动 Raspberry Pi

- [ ] 用 XT60 连接电池到机器人主电源
- [ ] 打开主电源开关
- [ ] **观察 Mini560 指示灯**（如有）确认通电
- [ ] 连接 HDMI 和键盘到 Pi 5，确认系统启动
- [ ] 检查 LD06 激光雷达 USB 连接，运行 `ros2 topic echo /scan` 验证点云输出
- [ ] **不接电机的情况下，关键是验证 Pi 和 LD06 稳定工作**

### 第三步：连接 STM32，验证 MCU 通信

- [ ] 用 USB 线连接 STM32 开发板的 USB 接口（或通过 Mini560 #2 的 5V 供电）
- [ ] 在 Pi 上运行 `sudo dmesg | tail -20` 检查 UART 设备是否识别（通常 `/dev/ttyS0` 或 `/dev/ttyAMA0`）
- [ ] 运行串口监听工具（如 `picocom -b 115200 /dev/ttyS0`）
- [ ] 在 STM32 上发送心跳包（HEARTBEAT 帧，CMD_ID = 0x1F），验证 Pi 接收
- [ ] 确认 I2C 总线正常：`i2cdetect -y 1` 应显示 MPU6050 (0x68) 和 VL53L0X (0x29)

### 第四步：依次连接电机，空转测试

- [ ] **先连接 1 个电机** (例如 FL)，设置占空比 20%，空转 3 秒确认方向正确
- [ ] 从 STM32 读取编码器计数，确认变化（表示编码器接线正确）
- [ ] 逐个连接其他 3 个电机，重复上述测试
- [ ] 四个电机均成功运行后，进行 PID 调参（初始参数参考 `firmware/Core/Src/pid.c`）

### 第五步：全系统运行检查

- [ ] 启动 ROS2 驱动层：`ros2 launch mcr_bringup robot.launch.py`
- [ ] 验证底层反馈话题：`ros2 topic echo /odom_feedback` 应显示编码器计数、ToF、IMU、电池电压
- [ ] 启动遥控：`ros2 run teleop_twist_keyboard teleop_twist_keyboard`
- [ ] 在安全区域进行全向移动测试（前进、横移、旋转）
- [ ] 监控电机电流（如有电流表）：正常运行 0.3-0.8A/个，堵转峰值 <2A/个

### 电解电容安全检查

- [ ] **务必检查电解电容的极性（+/- 方向）**，接反会在通电瞬间爆炸
- [ ] 1000μF 25V 电容（12V 电机总线）：长脚接电池+，短脚接地
- [ ] 220μF 16V 电容（Mini560 输出）：长脚接 Mini560 输出 +，短脚接地
- [ ] 通电后监控电容温度（手指接近应无烫感），过热表示内部短路

### 故障排查

| 症状 | 可能原因 | 排查步骤 |
|------|---------|--------|
| Pi 启动后立即重启 | Mini560 #1 输出不稳定或接线虚接 | 用万用表测 5V 纹波，检查 XT60 接头接触 |
| STM32 无法通信 | UART 接线反向或波特率不匹配 | 用逻辑分析仪观察 TX/RX 波形，检查 CubeMX UART 配置 |
| 电机不转 | 方向 GPIO 故障、PWM 占空比为 0、或 TB6612 未使能 | 用万用表测 DIR 和 PWM 引脚电压，检查 STBY 引脚 |
| 编码器无反馈 | 编码器接线虚接或 TIM 配置错误 | 用万用表欧姆档测编码器 A/B 相电阻（通常 50-200Ω），用逻辑分析仪观察方波 |
| 电机堵转时 Pi 重启 | 电机噪声未隔离，12V 总线尖峰拉低 Mini560 输出 | 检查电解电容是否焊接，尝试并联更大容值（2200μF）或更高纹波电流的电容 |

## NRF24L01 无线遥控接线 (Wireless Remote)

机器人端 STM32 接 NRF24L01+ 接收模块,配合江协科技无线手柄实现全向遥控。详见 [docs/remote_control.md](remote_control.md)。

| NRF24L01 引脚 | STM32 GPIO | 说明 |
|------|---------|------|
| CE | PA8 | 片选使能 |
| CSN | PA15 | SPI 片选 (JTAG 释放后使用) |
| SCK | PB3 | SPI 时钟 (JTAG 释放后使用) |
| MISO | PB4 | SPI 数据入 (上拉输入) |
| MOSI | PB5 | SPI 数据出 |
| VCC | 3.3V | 必须 3.3V,不可接 5V |
| GND | GND | 共地 |

- 软件 SPI 驱动在 `firmware/Core/Src/nrf24l01.c`,引脚宏在文件顶部,换板子改宏 + `gpio_init()` 即可
- 引脚占用 PA15/PB3/PB4(默认 JTAG),初始化时已禁用 JTAG 释放
- 遥控启用:手柄按 K1;紧急停止:K9。失联 100 ms 自动急停
