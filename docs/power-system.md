# 3S 电池供电方案（当前实装基准）

**状态：2026-08-22。** 本文档取代 `docs/wiring.md` 中旧的“电机 VM 接 12V 总线”草案。

当前电池为 3S LiPo（3500 mAh）：标称 11.1 V、满电 12.6 V。白色平衡插头测得约
3 V / 7 V / 11 V 是正常的分段电压；它只接平衡充电器或低压报警器，**绝不接负载**。

## 目标拓扑

电机已经在 6 V 下完成四轮开环方向测试。因此 TB6612 的 `VM` 使用独立的 6.0 V
电机母线，而不是直接接 3S 电池。

```text
3S LiPo XT60
  │
  ├─ 10 A 刀片保险丝（红线，靠近电池）
  ├─ 总开关（12 V DC，额定至少 10 A）
  └─ 配电端子 / 分线排
      ├─ 电机 Buck：3S → 6.00 V，持续 >= 6 A、建议 >= 8 A
      │   ├─ TB6612 #1 VM（FL + FR）
      │   └─ TB6612 #2 VM（RL + RR）
      ├─ STM32 Buck：3S → 5.00 V（Mini560）
      │   └─ Blue Pill `5V` / `GND`
      └─ Pi Buck：3S → 5 V / 5 A（P05C，确认规格后）
          └─ Raspberry Pi 5 USB-C `POWER IN`
```

三路输出的 **GND 必须共地**；三路的正极绝不相连。TB6612 的 `VCC` 继续由 Blue Pill
的 3.3 V 提供，`VM` 才接 6.0 V 电机母线。

## 现有两块 Mini560 的临时接法

Mini560 不应并联输出。可先分别带一块 TB6612：

```text
分线排 ── Mini560 #1（调到 6.00 V）── TB6612 #1 VM/GND
       └─ Mini560 #2（调到 6.00 V）── TB6612 #2 VM/GND
```

这是低负载调试方案，不是最终电机供电方案。每块 Mini560 同时承受两台电机的起步和堵转
电流，可能发生掉压或过热保护。若出现某两个轮同时卡顿、STM32 重启或模块烫手，应停止
使用并换成单块 6 V、持续 >= 8 A 的同步 Buck。

最终 STM32 还需要**第三块** Mini560（调 5.00 V）。Pi 5 不与 STM32 共用 Mini560，
采用单独的 P05C/等效 5 V 5 A USB-C 电源模块。

## 选型与布线

| 位置 | 要求 |
| --- | --- |
| 电机 Buck | 输入覆盖 9–12.6 V；输出可调 6.00 V；持续 >= 6 A，推荐 >= 8 A；优先同步降压 |
| STM32 Mini560 | 输入接电池分线；输出先调为 5.00 V，再接 Blue Pill `5V/GND` |
| Pi P05C | 输入规格必须覆盖 12.6 V；确认是真正 5 V/5 A 的 USB-C 输出后，直连 Pi 5 的 USB-C 供电口 |
| 主线 | XT60、保险丝、开关、配电端子使用 14–16 AWG 硅胶线 |
| 电机支路 | Buck 到 TB6612 `VM/GND` 使用 18–20 AWG；不用面包板轨或杜邦线承担电机电流 |
| 滤波 | 每块 TB6612 的 `VM/GND` 旁并联 470–1000 uF、耐压 >= 16 V 的电解电容 |

电池接口使用 XT60 公头线（与电池实际插座配对）。保险丝只串红线；黑线从电池负极直接
回到配电端子的公共 GND。线束用焊接或压接端子加热缩管固定，不能只靠裸线和胶带。

## 首次上电步骤

1. 电池接入前，检查正负极和电容极性；测量 `VM` 与 `GND` 不应短路。
2. 每个 Buck 先只接输入，用万用表把输出调准：电机 6.00 V、STM32 5.00 V。
3. 断电后再接负载。先上 STM32 和 Pi，再空载测试单个电机，最后四轮测试。
4. 电机启动时复测 6 V 母线；明显跌落、模块发烫或 MCU/Pi 重启都说明电机 Buck 不够。
5. 使用 3S 平衡充和 LiPo 防火袋；低压报警建议设在 3.5 V/节，静置后不应低于 3.3 V/节。

调试时 ST-Link 只接 `SWDIO`、`SWCLK`、`GND`；不要用 ST-Link 的 3.3 V 线给已由电池
供电的目标板反向供电。
