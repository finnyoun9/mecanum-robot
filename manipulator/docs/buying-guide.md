# LeArm 采购与验收

## 已确定配置

购买 **LeArm 标准版散件 + STM32 核心模组**。第一单不购买 51、ESP32、K210 视觉、语音、深度相机、滑轨或传送带扩展。

散件的目的不是单纯省钱，而是亲手确认：每个关节的转轴关系、舵机承载方向、连杆长度、轴承/舵盘配合、机械限位、回差、重心和线束弯折半径。

## 下单前必须让卖家确认

1. 当前所选 SKU 的完整清单，尤其是六个舵机型号及其安装关节。
2. 舵机是否全部为串行总线舵机，通信电平、波特率和供电电压是多少。
3. 能回读哪些状态：位置、温度、电压、负载/电流、速度。
4. 是否公开完整协议帧、checksum 算法、寄存器表和错误码。
5. STM32 的准确型号、原理图、PCB 图和工程源码是否提供。
6. 源码是完整可编译工程，还是只有封装库/HEX。
7. 是否包含电源、舵机控制板、下载器/下载线、舵盘、轴承和全部螺丝。
8. 是否提供结构装配图、零件编号、机械尺寸和逆运动学资料。
9. 更换舵机、重复 ID、零位偏差和齿轮虚位的售后办法。

仅有“提供源码”四个字不够，要让客服发目录截图或资料清单。

## 主控选择

| Module | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| STM32 | C/HAL、FreeRTOS、DMA、中断、看门狗和调试链完整 | 联网需要 Pi/额外模块 | 主线选择 |
| ESP32 | Wi-Fi/BLE、Arduino/ESP-IDF 上手快，双核资源多 | 容易停在 App/联网 Demo，与目标岗位主线稍偏 | 后续对照 |
| 8051 | 寄存器和资源约束直观，成本低 | 性能、工具链、RTOS 和岗位覆盖弱 | 不购买 |

## 建议随单购买

| Item | Purpose |
| --- | --- |
| 一个同型号备用舵机或备用齿轮 | 装配/堵转损坏后不阻塞项目 |
| 卖家原配稳压电源 | 桌面阶段避免先猜供电规格 |
| 自锁急停开关和保险座 | 独立切断舵机电源 |
| USB-UART/总线调试工具 | 脱离机械臂调试单个舵机 |
| 匹配的端子和备用线 | 做线束和逻辑分析仪引出 |

## 到货顺序

### 1. 清点，不通电

- 按 BOM 给所有零件拍照、编号、称重。
- 核对舵机型号、标签、线序和机械零位标记。
- 按装配图区分不同长度螺丝，避免顶穿舵机外壳。
- 记录缺件、变形、毛刺、轴承卡滞和舵盘虚位。

### 2. 机械干装

- 先不接舵机电源，逐关节装配并手动检查干涉。
- 不强行转动带减速齿轮且不可回驱的舵机输出轴。
- 每装一级就记录连杆中心距、可动角和线束余量。
- 螺丝先轻锁，确认所有关节对正后再按对角顺序紧固。
- 暂不涂永久螺纹胶；验证无误后再决定需要的位置。

### 3. 单舵机电气验收

- 脱离机械结构逐个连接，扫描并记录 ID。
- 低速度、小角度试转，确认方向和零点。
- 读取卖家承诺的全部反馈值，保存 CSV。
- 检查重复 ID、异常噪声、空回、发热和通信超时。

### 4. 整机首次上电

- 上电前把所有关节放在安全姿态，设定低速和软限位。
- 逐轴使能，不一次给六轴动作组。
- 急停只切断舵机支路，调试主机保持运行并记录日志。
- 首次堵转测试只做低扭矩、短时间验证，不拿满扭矩硬顶结构。

## 暂不购买

- K210/WonderMV：第一版复用 Pi 5 摄像头。
- 深度相机：AprilTag 平面抓取稳定后再评估。
- ESP32/51 核心模组：没有必要为同一机械臂同时维护三套示例。
- 厂商移动底盘：复用现有 `mecanum-robot`。
- 语音和“大模型”模块：不增加嵌入式求职含金量。
